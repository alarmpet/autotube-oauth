개인정보처리방침 / Privacy Policy

시행일 / Effective: 2026-10-26

1. 누가 쓰나 / Who uses it

autotube는 운영자 한 명이 자기 PC에서만 쓰는 개인용 도구입니다. 다른 사람의 Google 계정에 접근하지 않습니다.
autotube is a personal tool used only by its single operator on their own computer. It does not access anyone else's Google account.

2. 접근하는 데이터 / Data accessed

Google Drive API(rclone)를 통해 운영자 본인 Drive의 지정 폴더에 완성 영상·자막·썸네일 파일을 올리고, 올린 파일 목록을 확인합니다.
Through the Google Drive API (rclone), it uploads finished video, subtitle and thumbnail files to designated folders in the operator's own Drive and lists those files to confirm the upload.

3. 저장과 공유 / Storage and sharing

인증 토큰은 운영자 PC의 rclone 설정 파일에만 저장됩니다. Google 사용자 데이터를 외부 서버로 보내거나, 판매하거나, 제3자와 공유하거나, 광고에 쓰지 않습니다.
The authorization token is stored only in the rclone configuration file on the operator's computer. Google user data is not sent to any external server, sold, shared with third parties, or used for advertising.

4. Google API 서비스 사용자 데이터 정책 / Google API Services User Data Policy

Google API에서 받은 정보의 사용과 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. 접근 해제 / Revoking access

운영자는 언제든 Google 계정 권한 페이지에서 접근을 해제할 수 있습니다.
Access can be revoked at any time from the Google Account permissions page.
